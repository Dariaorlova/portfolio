# Портфолио Dasha Orlova

Это обычный статический сайт. Для него не нужны сборка, терминал или установка
пакетов.

## Где что редактировать

- Главная страница: `index.html`
- Текст кейса: `Building UX Research Function.html`
- Цвета, размеры, отступы и остальные общие стили: `styles.css`
- Увеличение изображения в кейсе: `script.js`
- Изображения и локальные шрифты: `assets/`

## Как открыть в VS Code

1. Откройте эту папку в VS Code.
2. При необходимости установите расширение **Live Server**.
3. Откройте `index.html`.
4. Нажмите **Go Live** в нижней панели VS Code.

Страницу также можно открыть двойным нажатием на `index.html`.
